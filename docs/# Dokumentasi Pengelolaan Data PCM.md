# Dokumentasi Pengelolaan Data PCM

## Kontribusi Data

Melakukan penginputan dan pengelolaan
data pada website administrasi PCM
menggunakan Supabase.

## Data yang Dikelola

- Data Pengurus
- Data Majelis/Bidang
- Data Agenda
- Data Berita
- Data Profil Organisasi

## Tugas

- Memasukkan data ke dalam sistem.
- Memastikan kelengkapan informasi.
- Memeriksa kesesuaian data.
- Memastikan data berhasil tersimpan
  di database Supabase.
